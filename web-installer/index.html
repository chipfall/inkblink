InkBlink

E-book reader firmware for the Elecrow CrowPanel ESP32 2.13" E-paper (hardware V1.2). Version __VERSION__.

Your browser cannot talk to USB devices. Use Chrome or Edge on a computer (Windows, macOS, Linux). The page must be opened over https.

How to install

  1. Connect the reader to the computer with a USB-C data cable.
  2. Click Install, choose the serial port (usually USB-SERIAL CH340) and confirm.
  3. When asked about erasing: leave it unticked for an update – your books stay. Tick it only for the first install over the factory firmware or if the reader does not start after installing (this deletes all books and settings).
  4. Wait until it reports success. The reader restarts by itself.
No port in the list? Windows usually installs the CH340 driver by itself; if not, install the CH340 driver from the chip maker (WCH) and plug the cable in again.
Connects but does not start writing? Hold BOOT, press and release RESET, release BOOT, then click Install again.

Files and source

The release .bin files and the change log are on the project's GitHub Releases page. Source code: MIT license, except the display driver files, which are derived from the board manufacturer's sample driver (see THIRD_PARTY_NOTICES.md).
